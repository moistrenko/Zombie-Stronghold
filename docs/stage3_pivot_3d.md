# Этап 3 (pivot) — 3D foundation + wall HP + 1 zombie

## Смена видения

Итог игры: **3D**, не 2D side-view.  
Стена **внизу** экрана; мобы идут **сверху вниз**.  
Старый 2D layout (стена слева / спавн справа) снят с main.  
Файлы `scenes/units/turret.tscn`, `projectile.tscn` и 2D-скрипты турели — **устарели**, не подключены к main (этап 4 пересоберёт турель в 3D).

## Main scene

`res://scenes/battle/battle.tscn` (корень `Node3D`) — стартовая сцена в `project.godot`.

## Оси (зафиксировано)

| | |
|--|--|
| Плоскость движения | **XZ** (Y вверх) |
| «Вниз экрана / к стене» | **+Z** |
| Спавн | `z = -10` (верх экрана) |
| Стена | `z = 6` (низ экрана), front ≈ `z = 5.5` |

## Камера

- `Camera3D` position ≈ `(0, 18, 14)` — за стеной / выше поля
- rotation ≈ **-50°** по X (лёгкий наклон top-down)
- `fov = 50`, `current = true`
- `DirectionalLight3D` + тени

## Логика (как этап 2, в 3D)

- Wall HP **100**, `take_damage`, `hp_changed` / `destroyed`, HUD Label
- 1 зомби (зелёный BoxMesh) идёт **+Z** к стене, `contact_damage = 10`, `queue_free`
- `move_speed = 3.0` world units/s
- Турель на этом этапе: **нет**

## Как проверить

1. Godot 4.3+ → открыть `project.godot` → **F5**
2. Вид: плоскость, стена ближе к низу кадра, красный маркер спавна сверху
3. Зелёный блок едет сверху вниз (~5 с), бьёт стену → HP `90/100`, исчезает
4. Стена слегка краснеет; при HP≤0 в Output: `defeat`

## Следующий шаг

Одна **3D-турель** у стены с автоатакой (снаряд или hit) по ближайшему зомби в группе `zombies`, баланс: убивает до стены.
