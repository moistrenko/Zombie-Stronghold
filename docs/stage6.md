# Этап 6 — placement турели по тапу

## Что сделано

- Стартовая фиксированная турель **убрана** (старт: 0 турелей).
- Тап/клик по земле → raycast камеры на плоскость **y = 0** → `turret.tscn`.
- Ввод: `InputEventScreenTouch` + ЛКМ (`InputEventMouseButton`) через `_unhandled_input`.
- HUD: `Turrets: N/3` (справа сверху).
- Полупрозрачная полоса `PlacementZone` у стены (подсказка зоны).
- Волны / win / lose / Restart без изменений по логике.

### Правила размещения

| Правило | Значение |
|---------|----------|
| `max_turrets` | **3** |
| `min_turret_distance` | **2.0** |
| Зона X | **-6 … 6** |
| Зона Z (у стены) | **2.0 … 5.5** |

Вне зоны / слишком близко / лимит — тап игнорируется (без магазина/золота).

### Raycast

1. `camera.project_ray_origin/normal(screen_pos)`
2. Пересечение с плоскостью `y = 0`
3. Проверка зоны + дистанции → `add_child(turret)` at `(x, 0, z)`

## Как проверить (F5)

1. Старт без турелей; синяя полоса у стены.
2. Клик/тап **в полосу** — ставится турель, счётчик `1/3` …
3. Клик у спавна / вне зоны — ничего.
4. Поставить 2–3 турели → пройти волны до VICTORY.
5. Не ставить турели → ожидаемо DEFEAT.
6. RESTART сбрасывает слоты.

## Баланс

- 0 турелей → поражение.
- 2–3 турели у стены → волна 3 проходима (как задумано).
- Статы турели без изменений (range 12, interval 0.7, dmg 15).
