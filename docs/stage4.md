# Этап 4 — 1 турель 3D + автоатака

## Что сделано

- **Turret** (`scenes/units/turret.tscn` + `scripts/units/turret.gd`): синий меш у стены `(0, 0, 5)`, автопоиск в группе `zombies`, стрельба без ввода игрока.
- **Projectile** (`scenes/units/projectile.tscn` + `scripts/units/projectile.gd`): жёлтая сфера, летит к цели, наносит урон.
- Зомби: уже имел `take_damage` / смерть; мёртвый стену не бьёт.
- Камера и оси **не менялись**.

## Как проверить

1. Godot → `project.godot` → **F5**
2. У стены снизу — синяя турель; сверху спавнится зелёный зомби
3. Жёлтые снаряды летят к зомби
4. Зомби исчезает **до** стены; Wall HP остаётся `100 / 100`
